# 2026-10-26: the 1.7.0 spanning acceptance run on home2

`scripts/span-acceptance.sh` on the real drive: ADR-0012 item 137, with item 139's tape 2, run
again in full after #497's fix (item 177). It ran from 2026-10-26 21:27:03 to 2026-10-27 14:08:36

production home, the production binary and every production cartridge were left alone.
